# LLM Wiki Starter

Личная база знаний с AI, которую можно собрать под себя. Сохраняй полезные материалы, решения и готовые тексты, а потом проси помощника находить нужное и учитывать твой контекст.

**Внутри пустой каркас.** Личные сведения, аккаунты, письма и знания автора сюда не включены. Ты заполняешь систему своими материалами, которые остаются в твоей отдельной приватной папке.

## Первый раз здесь?

1. Прочитай **[простое объяснение: как всё работает](docs/HOW-IT-WORKS.ru.md)**. Оно рассчитано на человека без технической подготовки.
2. Открой **[пошаговую установку](docs/INSTALL.ru.md)** и выбери подходящий способ.
3. Скачай комплект: кнопка **Code → Download ZIP** вверху репозитория. Готовый проверенный архив также доступен на странице [Releases](https://github.com/babichev/llm-wiki-starter/releases).
4. Прикрепи архив к новому чату ChatGPT и отправь сообщение ниже. Если архив не читается, вставь в чат [полный стартовый промпт](prompts/START-HERE.ru.md).
5. Ответь на короткие вопросы помощника. Он должен настроить систему под тебя и показать результат первого сохранения.

```text
Создай для меня личную систему знаний по приложенному LLM Wiki Starter.
Прочитай prompts/START-HERE.ru.md и выполни его. Сначала проверь свои
инструменты и задай короткие вопросы обо мне. Затем создай рабочие файлы,
настрой понятные правила и проверь первое сохранение и поиск по базе.
Объясняй каждый необходимый шаг простыми словами. Не переноси чужие
личные данные. Если ты не можешь менять файлы на моём компьютере,
подготовь скачиваемую базу и объясни следующий шаг. Подключения и
расписания называй работающими только после реальной проверки.
```

Сохранённое сообщение есть в [SHARE.ru.txt](prompts/SHARE.ru.txt). После настройки пригодится **[памятка: что говорить помощнику каждый день](docs/EVERYDAY.ru.md)**.

## Что это даёт

Представь шкаф с папками и помощника, который умеет раскладывать записи. Ты передаёшь ему заметку или статью. Он сохраняет оригинал, обновляет подходящую страницу и оставляет ссылку, откуда взял информацию. Позже ты спрашиваешь: «Что мы решили по этому проекту и почему?» — и получаешь ответ по сохранённым материалам.

Система помогает помнить контекст, но не делает любые сведения правдивыми. В ней различаются проверенный факт, слова участника встречи, предположение и принятое решение. Если источники противоречат друг другу, вопрос остаётся видимым.

## Два способа начать

| Способ | Что получится | Что понадобится |
| --- | --- | --- |
| Начать в обычном ChatGPT | Создать правила, личный контекст и доступные файлы. Работать с переданными материалами | Чат с доступными инструментами. Часть действий может остаться ручной |
| Полная локальная база | Читать и обновлять отдельную папку знаний, использовать локальные навыки и резервные копии | Помощник с доступом к выбранной папке. Для файлового инструмента — Python 3.10+. Obsidian удобен для просмотра, но необязателен |

Ссылка на репозиторий не даёт чату доступ к компьютеру, почте или всем прошлым разговорам. Для регулярного автоматического обновления нужен отдельно настроенный исполнитель. Локальные запуски требуют доступного компьютера и работающего приложения. Сначала проверь один ручной цикл, затем включай расписание. Различия описаны в [матрице сред](docs/PLATFORMS.ru.md).

## Установка локального каркаса

Это технический вариант для файлового помощника. Новичку достаточно следовать [простой инструкции](docs/INSTALL.ru.md) и поручить команды помощнику.

Из распакованной папки комплекта:

```bash
python3 scripts/wiki.py init --vault "/absolute/path/to/my-private-wiki"
```

Замени пример на фактический путь новой базы. Комплект и личная база должны быть отдельными, невложенными папками. Установщик не перезаписывает конфликтующие файлы. Он копирует каркас, файловый инструмент и шесть core skills в `.agents/skills` новой базы. Обнаружение навыков проверяется в конкретной среде.

После установки внутри новой базы:

```bash
python3 system/scripts/wiki.py status
python3 system/scripts/wiki.py audit
```

Файловый инструмент использует только стандартную библиотеку Python. Он ведёт учёт, но не делает смысловой синтез, не подключает аккаунты, не создаёт расписания и не публикует заметки.

## Личные знания хранятся отдельно

Скачанный публичный комплект — образец шкафа, а не место для твоих личных вещей. Не добавляй свои заметки, переписку, ключи или резервные копии в этот публичный репозиторий. Личную базу создавай отдельно. Публичным может быть только проверенный обезличенный шаблон. Подробнее: [правила публикации](docs/PUBLISHING.ru.md).

Starter kit распространяется бесплатно по [MIT license](LICENSE). Выбранный AI-сервис, облачное хранилище и подключения могут иметь собственные условия и стоимость. Сам комплект не требует платных API или передачи материалов неизвестному сервису.

## Разработка и помощь

```bash
python3 -m unittest discover -s tests -v
python3 tooling/check_links.py
python3 tooling/release.py scan
```

Сборка проверенного ZIP вне папки исходников:

```bash
python3 tooling/release.py build --output /absolute/path/to/releases/llm-wiki-starter-v1.1.0.zip
```

В архив добавляется список файлов с SHA-256, рядом сохраняется контрольная сумма ZIP. Публичный GitHub запускает тесты и проверку ссылок через [CI](.github/workflows/ci.yml).

# Настроить и применить стиль

Прочитай wiki/personal/tone-of-voice. Для настройки запроси небольшие примеры и аудиторию. Не требуй личную переписку, если достаточно обезличенного фрагмента.

Выдели наблюдения: порядок мысли, длина, прямота, обращение, терминология, примеры удачных и нежелательных фраз. Покажи короткую переработку одного материала. Вывод по примерам — гипотеза до подтверждения владельцем.

После согласования обнови канон через writer lease и укажи дату/основание. Для новой аудитории можно временно адаптировать текст без изменения глобального стиля.

При редактировании сохрани смысл, факты, числа, уровень уверенности и личный вклад. Если текст нужен для копирования, дай сначала чистовую версию. Архивный утверждённый текст не переписывай задним числом.

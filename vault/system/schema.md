# Схема документов и доказательств

Каждая содержательная заметка имеет YAML: `id`, `title`, `type`, `status`, `version`, `created`, `updated`, `closed`, `replaces`, `replaced_by`, `owner`, `access`, `source_refs`. Исключения — AGENTS.md как инструкции среды и технические Markdown рядом с программами.

`status`: draft, active, needs-review, closed, superseded, archived. Для superseded укажи `replaced_by`. При смысловой правке обнови version, updated и краткую историю, сохрани manual notes. `review_after` добавляй только с осмысленной датой проверки. Не сдвигай её без содержательного пересмотра. `valid_as_of` отражает давность знания, а не время записи файла.

`access`: public, internal, confidential, private. Это метка, не ACL. Рабочий vault по умолчанию private. При синтезе сохраняй ограничения источника, не переносить закрытые сведения в публичный вывод.

Различай **факт из источника**, **заявление участника**, **аналитический вывод**, **гипотезу**, **решение пользователя**, **неизвестное**. Встреча подтверждает факт сказанного, а не достоверность любых цифр участника. Ссылки на источник, дата события и дата проверки стоят рядом с существенным утверждением.

Для источника нужны стабильный key, тип, название, URL или локальный путь, дата источника, дата получения, хеш версии, полнота, доступ и состояние. Runtime ведёт версии и обработку в system/state. При изменении содержания сохраняется новая raw-версия, старую не перезаписывать. `pending` означает ожидает синтеза, `processed` — прочитан и отражён в проверенных файлах, `needs-review` — неполный материал или открытый вопрос. Записанный raw сам по себе не является обработанным знанием.

Сопоставляй сущности по устойчивому ID, официальному домену и источнику. Без домена используй стабильное известное имя, не угадывай. Одна организация может иметь несколько возможностей. Точный авторский текст хранится в artifacts, текущий синтез — в wiki.

Сохраняй обе конфликтующие версии, даты и вопрос на review. Новое письмо не является автоматическим разрешением изменить личные цели или выполнить внешнее действие.

# Архитектура

| Слой | Назначение |
| --- | --- |
| inbox, Clippings | Входящий материал до обработки |
| raw | Версии использованных источников, доступ ограничен файловой системой |
| wiki | Канонический синтез и связи |
| artifacts | Готовые тексты, таблицы, документы и другие результаты |
| system | Конфигурация без секретов, состояние, отчёты, проверки |
| playbooks, templates | Обслуживаемые процедуры и шаблоны |
| .agents/skills | Устанавливаемые локальные навыки |
| archive | Закрытые и заменённые документы |

Источник → снимок версии → утверждения и решения → сопоставление сущностей → канонический файл → зависимые выводы → проверка и отчёт.

Облачная синхронизация не равна резервированию, Git не равен опубликованной копии, папка Obsidian не равна памяти всех чатов. Выбери один канонический vault. Приватные файлы хранятся отдельно от публичного starter kit.

Агенты используют writer lease из runtime. Прямые правки Markdown должны соблюдать тот же протокол. Он не предотвращает ручное редактирование другим приложением, поэтому перечитай целевой файл перед записью.

Подключения и scheduler — адаптеры текущей среды, их нет в этом пакете как работающих сервисов. Внешние app tools нужно отдельно подключить и проверить. Никакая команда CLI не выполняет смысловой синтез вместо LLM.

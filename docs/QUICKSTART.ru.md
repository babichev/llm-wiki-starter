# Как запустить свою Wiki

Комплект содержит нейтральный шаблон и процедуры. Личные данные заполняются владельцем новой базы; подключений к его аккаунтам и активных расписаний в архиве нет.

## Самый простой запуск через чат

1. Прикрепи ZIP комплекта к ChatGPT или открой распакованную папку в среде с файлами.
2. Отправь текст из [SHARE.ru.txt](../prompts/SHARE.ru.txt). Основной запрос находится в [START-HERE.ru.md](../prompts/START-HERE.ru.md).
3. Ответь на небольшое интервью. Для полной локальной системы выбери папку новой приватной базы и исполнителя, который реально может читать и писать в ней.
4. Получи созданные файлы или скачиваемый архив, проверь свой профиль и tone of voice. Подключи один нужный источник, выполни ручное обновление. Затем включай расписание.

Если архив не читается, передай основной промпт текстом. Его достаточно для создания структуры с нуля, но готовый runtime и установленные навыки потребуют файловой среды.

## Установка файловым исполнителем

Нужен Python 3.10 или новее. Распакуй комплект в отдельную папку, открой терминал в её корне и выполни:

```bash
python3 scripts/wiki.py init --vault "/absolute/path/to/my-private-wiki"
```

Вместо `/absolute/path/to/my-private-wiki` укажи новый абсолютный путь. Это пример, не готовое значение. Не выбирай папку самого комплекта и не используй публичный репозиторий шаблона для личных записей. Команда не должна перезаписывать существующие файлы; коллизию нужно разобрать до продолжения. Список команд и конкретные аргументы — в [CLI.md](../scripts/CLI.md).

Открой созданную папку как vault в Obsidian либо как обычный файловый проект. Проверь `second-brain-home.md`, `wiki/index.md`, `system/config.json` и `system/setup-status.md`. Настрой язык, владельца, часовой пояс, ограничения, разрешённые источники и путь backup. Значения шаблона, не подтверждённые пользователем, остаются черновыми.

Навыки для локального Codex лежат в `.agents/skills` созданной базы. Их фактическое обнаружение проверь в текущей среде. Ручное чтение SKILL.md в обычном ChatGPT полезно как процедура, но не подтверждает регистрацию навыка. Дополнительные варианты установки — в [каталоге skills](../skills/catalog.md).

## Первый полезный цикл

Выбери один материал, который разрешено сохранить: например, собственную заметку о проекте. Попроси:

> Сохрани этот материал в моей Wiki через wiki-capture. Покажи, где лежат исходная версия и канонический вывод. Гипотезы не превращай в решения.

После сохранения закрой исходный текст и попроси найти ответ по базе с указанием источника. Повтори импорт того же материала: нового дубля быть не должно. Затем проверь небольшое противоречащее уточнение — история и обе версии должны остаться видимыми до разрешения.

Для авторского голоса дай несколько собственных текстов и явные предпочтения. Попроси сформировать черновой tone of voice, показать пример и внести твои коррекции. Не утверждай автоматически все выводы по образцам.

Перед регулярной задачей выполни [daily-update](../prompts/daily-update.ru.md) вручную. Проверь отчёт, очередь источников, изменённые файлы и backup. Подключение без успешного чтения остаётся `configured`, расписание без успешного запуска — непроверенным.

## Что означает «готово»

| Проверка | Доказательство |
| --- | --- |
| База создана | Файлы существуют, главная навигация открывается |
| Контекст персонализирован | Профиль и ограничения проверены владельцем |
| Источник подключён | Получен конкретный разрешённый материал с датой и охватом |
| Обработка работает | Каноническая страница содержит новый вывод и ссылку на источник |
| Навык доступен | Текущая среда обнаруживает его либо явно читает процедуру |
| Автоматизация работает | Есть ID/ссылка, проверены доступы и результат запуска |
| Backup пригоден | Manifest проверен, восстановление прошло в отдельной пустой папке |

Повторный запуск настройки не должен создавать вторую базу, дублировать расписание или заменять ручные файлы. Если среда умеет только создавать архив, это рабочая поставка каркаса с последующей локальной установкой, а не проверенная эксплуатация на компьютере.

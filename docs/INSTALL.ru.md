# Установка шаг за шагом

Начать можно с обычного ChatGPT и одного архива. Для полноценной работы с папкой на компьютере понадобится помощник, который умеет читать и менять локальные файлы. Ниже два пути. Выбирай один, не пытайся выполнить оба одновременно.

Если пока непонятно, что ты устанавливаешь, сначала прочитай [простое объяснение](HOW-IT-WORKS.ru.md).

## Сначала скачай комплект

1. Открой главную страницу этого репозитория.
2. Нажми **Code → Download ZIP**. Это скачает набор файлов. Если на странице есть раздел Releases с архивом выпуска, можно взять архив оттуда.
3. Найди ZIP в загрузках. Пока не добавляй в него свои документы.

GitHub здесь служит магазинной полкой, с которой ты берёшь пустой комплект. Твоя будущая личная база должна лежать отдельно. Создавать для неё публичный репозиторий через **Use this template** не нужно.

## Путь 1. Начать в обычном ChatGPT

Этот путь подходит, если ты хочешь сначала попробовать систему без установки Python и работы в терминале. Результат — подготовленные файлы и ручной процесс. Автоматическая запись в папку компьютера этим не включается.

### 1. Передай комплект чату

Открой новый чат и прикрепи скачанный ZIP, если загрузка файлов доступна. Отправь:

```text
Я хочу начать свою личную базу знаний. Используй приложенный LLM Wiki Starter.
Открой prompts/START-HERE.ru.md и помоги пройти настройку простыми словами.
Сначала проверь, что ты умеешь в этой среде. Задай короткое интервью,
затем создай доступные здесь файлы или скачиваемый архив.
Я не технический человек. Для каждого необходимого действия объясняй,
что мне нажать или передать и как проверить результат.
```

Если чат не читает ZIP, распакуй его, открой файл `prompts/START-HERE.ru.md`, скопируй текст целиком и отправь сообщением. Файл можно открыть обычным текстовым редактором. Либо открой [стартовый промпт прямо здесь](../prompts/START-HERE.ru.md) и скопируй его содержимое.

**Проверка:** чат назвал свои реальные возможности и ограничения, а не сразу заявил «всё установлено».

### 2. Ответь на вопросы о себе

Обычно нужны цели системы, области работы, язык, удобный стиль, место хранения и разрешённые источники. Расскажи только то, что полезно задаче. Доход, семейные обстоятельства и другие чувствительные подробности необязательны.

**Проверка:** профиль содержит твои ответы. Неизвестное отмечено как неизвестное, чужие цели не появились.

### 3. Забери результат

Попроси дать созданные файлы одним скачиваемым архивом, если чат умеет его создавать. Сохрани архив и распакуй в отдельную приватную папку, например с понятным тебе названием «Мои знания».

Если чат умеет только писать текст, попроси по одному выдать главную страницу, профиль, текущие цели и правила общения с точными именами файлов. Это более ручной вариант. Чат должен прямо назвать его таким.

Если используешь проект ChatGPT, добавь [инструкции проекта](../prompts/project-instructions.ru.md) и небольшой актуальный набор файлов. Проект помогает держать связанные чаты и материалы вместе, но не делает папку компьютера автоматически доступной. Подробнее — в [официальной справке проектов](https://learn.chatgpt.com/docs/projects).

**Проверка:** ты можешь найти и самостоятельно открыть полученные файлы. Ты знаешь, где хранится главная копия, а где только переданный чату снимок.

### 4. Проверь одну заметку

Для первого опыта используй вымышленную запись: «Учебный книжный клуб встречается по вторникам». Попроси сохранить её отдельно как учебный пример, затем найти день встречи по базе и показать источник. Повтори сохранение: второй одинаковой карточки быть не должно.

Потом передай другой учебный источник: «Встречи книжного клуба по четвергам», не называя это новым решением. Попроси показать противоречие. Обе версии должны остаться видимыми до твоего уточнения. Учебные сведения не должны попасть в твой личный профиль.

В ручном веб-режиме после изменений скачивай обновлённые файлы и сохраняй их в выбранной главной папке. При новом обращении передавай актуальную версию. Не считай старый загруженный файл автоматически обновлённым.

## Путь 2. Полная система в папке компьютера

Этот путь удобнее для постоянного использования. Нужна среда с доступом к выбранным локальным файлам, например соответствующий режим ChatGPT/Codex. Наличие приложения само по себе не доказывает, что доступ уже есть.

Для файлового инструмента комплекта нужен **Python 3.10 или новее**. Python — программа, которая запускает небольшие служебные команды. Obsidian можно использовать для удобного просмотра и ручной правки заметок, но он не обязателен для чтения обычных текстовых файлов.

### 1. Раздели комплект и свои знания

Распакуй ZIP. Выбери место для двух отдельных папок рядом:

```text
Выбранное тобой место/
  llm-wiki-starter/   ← скачанный пустой комплект
  my-private-wiki/    ← твоя будущая личная база
```

Не помещай одну внутрь другой. Личные записи будут появляться только во второй папке. Если там уже есть важные файлы, скажи об этом помощнику до установки.

### 2. Открой комплект в файловом помощнике

Открой распакованную папку комплекта как локальный проект и передай:

```text
Настрой LLM Wiki по prompts/START-HERE.ru.md.
Сначала проверь, можешь ли ты читать и создавать файлы в выбранных папках.
Проверь Python 3.10+. Если его нет, помоги выбрать официальную установку
для моей системы и объясни действие, которое мне действительно нужно сделать.
Не проси меня запускать непонятные команды из случайных сайтов.
Создай мою базу в отдельной согласованной папке, сохрани существующие файлы.
Технические команды выполни сам в пределах доступных прав.
```

Не передавай помощнику пароли или ключи. Если приложение просит доступ к конкретной папке, проверь, что это именно выбранная папка.

### 3. Дай помощнику выполнить установку

В комплекте есть команда, которая переносит шаблон, инструкции и шесть навыков в новую базу. Вот её вид для понимания:

```bash
python3 scripts/wiki.py init --vault "/absolute/path/to/my-private-wiki"
```

`/absolute/path/to/my-private-wiki` — место для твоего фактического полного пути, а не готовая команда для копирования. Путь зависит от компьютера. Помощник должен подставить его после проверки. Команда запускается из папки комплекта и не должна перезаписывать конфликтующие файлы. Если возник конфликт, сначала надо разобраться с ним.

**Проверка:** помощник показывает созданную папку, главную `second-brain-home.md`, индекс и результат проверки структуры. В папке `.agents/skills` должны быть шесть навыков, но их обнаружение в приложении проверяется отдельно.

### 4. Открой уже свою базу

Теперь открой папку `my-private-wiki` как рабочую папку помощника. По желанию открой эту же папку в Obsidian как существующую базу заметок. Важно: оба приложения должны работать с одной и той же личной папкой.

Ответь на интервью и проверь свой профиль, цели и стиль. Если твоя настоящая предпочтительная манера — короткие ответы на русском, скажи это прямо. Помощник не должен принимать примеры из инструкции за сведения о тебе.

**Проверка:** ты можешь открыть главную страницу и перейти по ссылкам. Помощник называет фактическую личную папку, а не папку шаблона.

### 5. Выполни первый круг и проверь копию

Повтори учебный опыт с книжным клубом из первого пути либо выбери одну собственную несекретную заметку. Попроси сохранить, найти ответ с источником и проверить повтор без дубля.

Затем попроси:

> Сделай резервную копию моей базы в отдельной согласованной папке. Проверь восстановление в новую пустую папку. Рабочую базу не заменяй. Покажи, где лежит проверенная копия.

Резервная копия — запасной экземпляр на случай ошибки или поломки. Проверка восстановления показывает, что из неё действительно можно получить файлы. Копия на том же диске не спасает при потере всего диска. Выбор второго носителя или защищённого хранилища делается отдельно. Встроенная копия не шифруется.

## Подключения и расписание — после первого успешного круга

Сначала разреши один понятный источник, например отдельную папку документов. Попроси показать один прочитанный материал и то, как он изменил страницу знаний. Не начинай с доступа ко всем аккаунтам.

Затем выбери время обновления и часовой пояс. Попроси настроить существующий доступный механизм расписаний по [инструкции](AUTOMATIONS.ru.md). Задача считается проверенной, когда есть её реальная запись и результат запуска. Подготовленный текст расписания сам ничего не запускает. Для работы с локальной папкой компьютер и нужное приложение должны быть доступны.

## Если что-то не получается

| Ситуация | Что сделать |
| --- | --- |
| Чат не открывает GitHub-ссылку | Прикрепи ZIP либо скопируй полный стартовый промпт. |
| Чат не умеет читать ZIP | Распакуй и передай нужный текст или файлы. |
| Помощник не видит папку компьютера | Перейди к ручному веб-пути либо открой папку в среде с файловым доступом. |
| Помощник сообщил об установке без файлов | Попроси реальные пути и проверку чтением. Если файлов нет, установка не подтверждена. |
| Нет расписаний в твоём аккаунте | Пользуйся ручным обновлением. Подготовленный промпт можно применить позже. |
| Локальная задача пропустила запуск | Проверь доступность компьютера, приложения и папки, затем результат следующего запуска. |

Сам комплект не требует платных API. Доступ к выбранному AI-приложению, подключённым сервисам или облачному хранению зависит от их условий и твоего аккаунта. Не подключай платную услугу только потому, что её упомянул помощник.

После установки используй [пять повседневных команд](EVERYDAY.ru.md). Технические подробности остаются в [справке команд](../scripts/CLI.md), когда они понадобятся.

# Проверка выпуска 1.1.0

Дата проверки: **15 ноября 2026**. Это проверка переносимого комплекта на синтетических данных, не установка у нового владельца.

## Выполнено

- **14/14 интеграционных тестов runtime прошли.** Проверены недеструктивный и повторный init, коллизии до копирования, запрет вложения и symlink, собственность/истечение lease, версии источников, отказ при отсутствующем/повреждённом raw, SHA обрабатываемой версии, обновление метаданных, сохранение ручного индекса, backup/restore, повреждённая копия и небезопасные пути восстановления.
- **6/6 skills прошли официальный структурный quick_validate.** Это проверка формата, не доказательство качества решения любой задачи. YAML UI metadata проверялся отдельно.
- **Шаблон vault прошёл audit.** В нём 40 Markdown-файлов. Проверены основные поля, идентификаторы и цели внутренних ссылок. Проверка не определяет истинность содержания, якоря заголовков или доступность внешних URL.
- **Выполнен сквозной capture в отдельной временной базе.** Сохранены raw, решение в каноне, точный TXT без редакции и отчёт. Readback и SHA совпали. Команда, внедрённая внутрь источника, осталась данными. Индекс сохранил ручной текст, audit завершился без ошибок, lease освобождена. Первый вызов mark с TXT в links был безопасно отклонён и исправлен на Markdown-ссылки. Этот прогон использовал runtime до добавления обязательного digest gate, новый gate отдельно проверен интеграционными тестами и повторным review.
- **Найденные при дополнительном review ошибки ingest/mark исправлены.** Повторная независимая проверка подтвердила отказ при missing/corrupt raw, stale SHA и корректное обновление coverage/дат/чувствительности/типа доказательства без дублирования raw.
- **Состав публичного комплекта просмотрен.** Поиск имён, реальных проектов, пользовательских путей и приватных маркеров автора не дал совпадений. Автоматический release scan проверяет очевидные форматы секретов и симлинки. Он не заменяет смысловой просмотр.

Команда тестов из корня комплекта:

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v
python3 tooling/release.py scan
```

Тестовая среда: macOS, Python **3.9.6**. Скрипт не использует внешние пакеты. Для установки документирован Python **3.10+**. Отдельная матрица разных ОС и версий Python не выполнялась. PyYAML был нужен только внешнему официальному skill validator и не входит в зависимости комплекта.

## Что проверяет поставка

ZIP собирается только из публичных разделов, содержит `release-manifest.json` с SHA-256 каждого файла. Рядом с архивом сохраняется SHA-256 самого ZIP. Итоговый архив распаковывается в отдельную временную папку, хеши и установка из распакованного комплекта проверяются повторно. Точный результат упаковки хранится в локальном receipt поставки, а не в этом исходном шаблоне.

## Дополнения к публичному выпуску

Добавлены понятное объяснение для новичка, пошаговая установка, ежедневная памятка, правила участия и безопасности, формы сообщений и CI. Проверки публикации включают два прохода по приватности: автоматическое сканирование состава и независимое чтение всех файлов. Итог проверяется перед загрузкой и по содержимому опубликованного commit. Настройки GitHub и результаты CI подтверждаются отдельно в receipt публикации.

## Границы

В этом выпуске не выполнялись OAuth/подключение аккаунтов нового владельца, чтение его почты, создание его расписаний, реальный плановый фоновый запуск, облачная синхронизация, установка в его Obsidian на устройстве нового владельца. Они требуют доступной среды, настроек и фактической проверки после переноса.

Backup не шифруется, исключает только известные служебные объекты и имена credential-файлов. Все секреты по содержимому он не распознаёт. Lease координирует участников протокола и не блокирует ручной редактор. Смысловые изменения канонических страниц выполняет агент, а не Python CLI.

Текущие возможности продуктов проверялись по официальным источникам из [PLATFORMS.ru.md](PLATFORMS.ru.md). После изменения среды их надо проверить снова.

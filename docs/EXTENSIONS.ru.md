# Расширение системы навыками и сервисами

Шесть core skills уже лежат в комплекте. Для Codex они устанавливаются локально вместе с базой и не требуют API. Их наличие не даёт доступа к почте, Notion или облачным дискам.

Добавляй расширения после первого успешного рабочего цикла. Для каждого достаточно записать в приватной базе назначение, trigger, источник/версию, нужные инструменты, доступы, ожидаемый результат и способ проверки. Большой каталог не означает рабочую систему.

| Потребность | Что подключить |
| --- | --- |
| Создавать новые процедуры | Поставляемый `wiki-skill-builder` или штатный `skill-creator`, если он доступен |
| Установить внешний локальный skill | Штатный `skill-installer` при его наличии либо проверенную папку в поддерживаемый каталог |
| Встречи | Штатное подключение выбранного сервиса с доступом к конкретной базе/папке |
| Почта | Разрешённый аккаунт и тематические запросы с чтением без изменения писем |
| Веб-материалы | Obsidian Web Clipper или существующий выбранный способ сохранения |
| Документы, таблицы, слайды | Доступные в среде специализированные инструменты, когда они нужны реальным задачам |
| Предметная работа | Новый отдельный skill по повторяющейся задаче владельца, с входами, выходами и проверкой результата |

Локальная установка выбранного внешнего навыка не равна установке плагина в браузерный ChatGPT. Доступные способы различаются. Папки локальных навыков, `skill-creator`, `skill-installer` и распространение через плагины описаны в [официальной справке](https://learn.chatgpt.com/docs/build-skills), проверенной 15 ноября 2026 года. Прежде чем ставить пакет, проверь текущие инструкции, права на распространение и содержание скриптов.

Этот starter не перепаковывает сторонние платные навыки или чужие подключённые плагины. Не устанавливай весь набор автора примера: выбирай процедуры по своей работе и измеряй их пользу готовым результатом, временем и стоимостью. Никакие платные API для базовой файловой системы не нужны. Подписка или внешние услуги могут потребоваться выбранному пользователем исполнителю и подключениям, их условия проверяются отдельно.
